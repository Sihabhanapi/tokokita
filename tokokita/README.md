# TokoKita
Aplikasi toko Android (Kotlin + Jetpack Compose + Room). Tema gelap emas elegan.
Fitur: produk (CRUD + foto), kasir, laporan harian/bulanan + ekspor CSV, struk, backup/restore, pengaturan toko.
kasir + keranjang, riwayat transaksi, dashboard (penjualan hari ini, nilai stok, stok menipis).
ABI: armeabi-v7a & arm64-v8a. Build: GitHub Actions -> Artifacts "TokoKita-armeabi-v7a" dan "TokoKita-arm64-v8a".
